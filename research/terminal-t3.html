The language choice has two answers

New native client: Rust

Native code, no GC or JIT, mature terminal and protocol libraries. Ratatui diffs cell buffers; the application controls when it draws.

Cost: port V2 state and keep contracts, auth, resume and pagination correct.

Fastest V2 delivery: TypeScript

OpenTUI's Zig core handles native rendering. The existing fork shares T3's contracts and reducers directly.

Cost: runtime memory and JS update work. Optimize timers and transcript caching before judging it.

The battery rules I would enforce

  1. Wait for input, socket, resize and focus events. Draw only when dirty. No permanent idle animation.
  2. Coalesce visual updates to at most 30 fps while streaming. Preserve all state events; flush approvals, errors and final states promptly.
  3. Cache completed message layouts. Reparse the changed message, render visible rows, and bound retained history and image caches.
  4. Replace Electron's host-power reporting. Send focus and visible-scope activity leases. Avoid preview discovery and diagnostic subscriptions when their panes are closed.
  5. Test V2 contract drift, sequence gaps, snapshots, reconnect, pagination, approvals and questions with replayed synthetic fixtures.

Removing Electron also removes its power reporter. In the checked source, stale host state bypasses the server's host-constrained battery checks. Fix this so the terminal client can still use T3's battery policy.

A remote client must not overwrite the remote host's power state with its laptop's state. Host reporting needs operate permission; activity reporting needs read permission. Policy, authorization.

Source findings and validation targets
  • Tria draws on a 120 ms repeating tick.
  • The TS fork's completed-turn label can retain a 250 ms clock.
  • Its conversation layout processes loaded history before viewport slicing.
  • Port discovery can launch lsof every three seconds while subscribed.

Proposed targets: zero idle frames, under 0.5% of one core over five minutes, at most one client-attributable idle wakeup per second, p95 typing echo under 50 ms, and stable active-message update cost as completed history grows.

Targets are not measured results. Compare release builds on the same backend and deterministic replay. Include the terminal and providers, fix brightness and power mode, and alternate at least five pairs of 5–10 minute runs. Report energy per completed task and measurement spread.
